# Claude / AI assistant instructions (Galdralag firmware)

This file is for **Claude Code**, **Claude Desktop** project context, and other assistants. **Cursor** loads the same expectations from **`.cursor/rules/*.mdc`**.

## Project

- **Galdr** / **Galdralag**: Rust firmware for **Baochip-1x** under **Xous**; OpenPGP card behaviour, vault, PIN policy, host tools (**Galdra**). Target: `riscv32imac-unknown-none-elf`.

## Rules of engagement

1. **No emojis** in code, comments, commits, or documentation.
2. **Ask before** git commit, push, or PR unless the user explicitly requested it in the current task.
3. **Minimal scope**: fix what was asked; avoid unrelated refactors and new files unless necessary.
4. **Run commands** (e.g. `cargo check`, tests) when diagnosing issues; do not only suggest commands.
5. **Plain-language glossary** for readers: [docs/GLOSSARY.md](docs/GLOSSARY.md).
