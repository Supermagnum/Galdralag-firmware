# NFC Antenna Selection and Matching Network Design

For the Galdralag / Dabao USB security token (Baochip-1x platform).

---

## Power Budget

The Dabao evaluation board (dabao_v3c) draws **5.06V × 0.049A = ~248mW** at idle,
supplied via USB 2.0 (2.5W maximum). The 3.3V rail is generated by a **MT3406**
synchronous buck converter capable of up to ~2W output. This leaves ample headroom
for a PN532 NFC controller:

| PN532 mode | Current draw | Power at 3.3V | Board + NFC total |
|---|---|---|---|
| Card emulation (passive) | ~15–20mA | ~60mW | ~308mW |
| Active reader | ~100–150mA | ~330–500mW | ~580–750mW |

Both scenarios are within the USB 2.5W budget. No additional power circuitry is
required — the PN532 connects directly to the existing 3.3V rail.

In the primary use case (tap-to-authenticate, card emulation mode), RF energy comes
from the *reader's* field rather than the token's USB supply, making the power impact
on the token nearly negligible.

## Antenna Options

### Option 1 — Molex 1462360101-ND (Digi-Key)

| Parameter | Value |
|---|---|
| Dimensions | 15mm × 25mm × 0.27mm |
| Type | Flexible PCB antenna (flat coil on thin substrate) |
| Frequency | 13.56 MHz |
| Typical read range | 20–40mm |
| Mounting | Adhesive / flexible |

**Pros:** Extremely thin (0.27mm — essentially a flat sticker). No height penalty.
Good read range. Can be folded around a housing interior.

**Cons:** 15×25mm footprint exceeds the available PCB area on the USB-A dongle
form factor. Best suited to the larger `dabao_v3c_sdcard` variant or a future
enclosure design where the antenna is mounted inside the housing and wired back
to the PN532 on the PCB.

### Option 2 — L000641-01 *(Recommended for dabao_v3c)*

| Parameter | Value |
|---|---|
| Dimensions | 7.8mm × 7mm × 5mm |
| Frequency | 13.56 MHz |
| Self-inductance (La) | 4.7 µH |
| DC resistance (DCR) | 0.25 Ω |
| Read distance | 35mm |
| Weight | 0.85g |
| Mounting | Surface mount |
| Operating temperature | −40°C to +85°C |

**Pros:** 7.8×7mm footprint fits on the USB-A dongle PCB without redesign.
Known La = 4.7µH makes PN532 matching network calculation straightforward.
35mm read range is good for deliberate tap-to-authenticate without accidental
triggering. Low DCR (0.25Ω) minimises resistive loss. Industrial temperature
range suits field deployment use cases (search and rescue, emergency comms).
Surface mount integrates into the existing assembly process.

**Cons:** 5mm height dictates minimum enclosure thickness.

**Verdict:** L000641-01 is the practical choice for the current dongle design.
1462360101-ND is better suited to larger or enclosure-based variants.

## Matching Network Calculation

The PN532 requires the antenna to resonate at **13.56MHz**. With a known antenna
inductance, the required tuning capacitance is calculated from the LC resonance
formula, then split into a matching network that also transforms impedance for
maximum power transfer.

### Step 1 — Resonant capacitance

The resonant frequency of an LC circuit is:

```
f = 1 / (2π × √(L × C))
```

Rearranged for C:

```
C_total = 1 / (4π² × f² × La)
```

With La = 4.7µH and f = 13.56MHz:

```
C_total = 1 / (4π² × (13.56 × 10⁶)² × (4.7 × 10⁻⁶))
        = 1 / (4 × 9.8696 × 1.839 × 10¹⁴ × 4.7 × 10⁻⁶)
        = 1 / (3.394 × 10¹⁰)
        ≈ 29.5 pF
```

The nearest standard E12 value is **33pF** (also the value used for the crystal
load capacitors C1/C9 on the dabao_v3c board, which use C0G dielectric — the
correct type for RF tuning: stable, low-loss, temperature-independent).

Using 33pF shifts resonance slightly:

```
f = 1 / (2π × √(4.7 × 10⁻⁶ × 33 × 10⁻¹²))
  = 1 / (2π × √(1.551 × 10⁻¹⁶))
  = 1 / (2π × 1.245 × 10⁻⁸)
  ≈ 12.78 MHz
```

This is ~6% below target. To trim back to 13.56MHz, use **27pF** or a parallel
combination such as **22pF + 8.2pF = 30.2pF** (closer to the calculated 29.5pF).
Fine tuning on the bench with a network analyser is recommended regardless of
the calculated value.

---

### Step 2 — PN532 matching network topology

NXP recommends a two-capacitor matching network per AN10609. The total tuning
capacitance is split between a series capacitor (C_s) and a parallel capacitor
(C_p) to simultaneously tune the resonant frequency and match the antenna
impedance to the PN532's TX output impedance (~20–40Ω differential).

```
PN532 TX pins
    │
   [C_s] ──── antenna ──── [C_p] ──── GND
              (La, DCR)
```

The split ratio depends on the antenna Q factor and the desired impedance
transformation. With DCR = 0.25Ω and La = 4.7µH at 13.56MHz:

**Antenna reactance (XL):**

```
XL = 2π × f × La
   = 2π × 13.56 × 10⁶ × 4.7 × 10⁻⁶
   ≈ 401 Ω
```

**Antenna Q factor:**

```
Q = XL / DCR
  = 401 / 0.25
  ≈ 1604 (unloaded — very high)
```

In practice the loaded Q (with the PN532 and receiver loading) will be
significantly lower (typically 10–30 for a well-matched NFC circuit). NXP
AN10609 provides a worked example and recommends targeting a loaded Q of
approximately 10–20 for robust operation across manufacturing tolerances.

**Capacitor split (approximate starting values):**

For a target loaded Q ≈ 15 and source impedance Rs ≈ 30Ω:

```
C_p = Q / (2π × f × Rs)
    = 15 / (2π × 13.56 × 10⁶ × 30)
    ≈ 5.9 pF  → use 5.6 pF (E12)

C_s = C_total − C_p
    = 29.5 − 5.9
    ≈ 23.6 pF  → use 22 pF (E12)
```

These are **starting values for bench tuning only**. Final values depend on
PCB parasitics, enclosure proximity, and the specific PN532 evaluation.

---

### Step 3 — EMC filter (recommended)

NXP recommends a small-signal EMC filter between the PN532 TX output and the
matching network to suppress harmonics at 27.12MHz, 40.68MHz, etc.:

```
PN532 TX ── [27Ω] ── [C_EMC 47pF to GND] ── matching network
```

The 27Ω series resistor and 47pF shunt capacitor form a low-pass filter with
a corner frequency well above 13.56MHz but below the first harmonic.

---

### Step 4 — Bench verification

Measure with a **network analyser** (NanoVNA is sufficient for 13.56MHz work):

1. Connect the antenna + matching network with no PN532 attached.
2. Measure S11 (return loss). The dip should be at or very close to 13.56MHz.
3. Adjust C_s and C_p to bring the resonance to exactly 13.56MHz.
4. With the PN532 connected, verify the impedance at the TX pins is close to
   the target (typically 40–80Ω depending on the driver mode selected).

## GPIO Connection to Baochip-1x

The PN532 supports SPI, I2C, or UART. The dabao_v3c netlist shows the PB and
PC GPIO banks are largely unconnected and available. SPI is recommended for
speed (up to 5MHz). Suggested pin assignment (adjust to avoid conflicts with
your specific Xous BSP):

| PN532 pin | Baochip-1x GPIO | Function |
|---|---|---|
| SCK | PB3 | SPI clock |
| MOSI | PB4 | SPI data out |
| MISO | PB5 | SPI data in |
| NSS | PB6 | SPI chip select |
| IRQ | PB7 | Interrupt (active low) |
| VCC | 3.3V rail | Power |
| GND | GND | Ground |

## Power and Ground Connections

### PN532 Power Supply

The PN532 has two power pins that must both be connected:

| PN532 pin | Connect to | Notes |
|---|---|---|
| VDD (pin 1) | +3.3V rail | Main supply — 3.0V to 3.6V range, 150mA max |
| VSS (pin 2) | GND | Ground reference |
| VBAT (pin 3) | +3.3V rail | Battery / supply pin — tie to VDD on USB-powered design |
| VBAT_GND (pin 4) | GND | Battery ground — tie to VSS |

On the dabao_v3c the +3.3V rail is net `+3.3V` generated by U3 (MT3406 buck).
The GND net is common throughout the board. Both are accessible at multiple
points near the unconnected GPIO header pads.

### Decoupling Capacitors (mandatory)

The PN532 datasheet requires decoupling capacitors as close as possible to the
VDD and VBAT pins. Without these the PN532 will behave erratically or fail to
power up correctly:

| Reference | Value | Type | Placement |
|---|---|---|---|
| C_VDD1 | 100nF C0G or X7R | 0402 | VDD pin — as close as possible |
| C_VDD2 | 10µF X5R | 0603 | VDD pin — bulk, within 2mm |
| C_VBAT1 | 100nF C0G or X7R | 0402 | VBAT pin — as close as possible |
| C_VBAT2 | 10µF X5R | 0603 | VBAT pin — bulk, within 2mm |

These are the same values and types already used throughout the dabao_v3c
design (C4/C6/C7 are 100nF X5R; C11/C14/C15/C16 are 10µF X5R), so no new
component types are introduced.

### Ground Plane Considerations

The PN532 VSS and VBAT_GND pins must connect to a **solid ground plane**, not
a thin trace. On the dabao_v3c 2-layer board:

- Use the bottom copper layer as a ground plane under the PN532 and antenna area.
- Connect all GND pins with **multiple vias** to the ground plane — do not rely
  on a single via.
- Keep the antenna matching network ground connections short and direct to the
  same ground plane. Long ground traces at 13.56MHz introduce parasitic
  inductance that detunes the matching network.
- **Do not route any signal traces under the antenna coil area.** The magnetic
  field couples into nearby conductors and degrades antenna performance.

### Complete PN532 Connection Summary

```
                    +3.3V (net: +3.3V)
                        │
                    [C_VDD2]  [C_VDD1]
                    10µF      100nF
                        │         │
PN532 ──── VDD  ────────┴─────────┘
      ──── VBAT ────────┬─────────┐
                    [C_VBAT2] [C_VBAT1]
                    10µF      100nF
                        │         │
      ──── VSS  ─────── GND plane
      ──── VBAT_GND ─── GND plane
                        │
                       ═══ (solid ground plane)

      ──── SCK  ──────── PB3  (Baochip-1x)
      ──── MOSI ──────── PB4
      ──── MISO ──────── PB5
      ──── NSS  ──────── PB6
      ──── IRQ  ──────── PB7
      ──── RSTPD_N ───── PB8  (reset/power-down, active low)
                         │
                        [R_PD]
                        10kΩ pull-up to +3.3V
```

### RSTPD_N (Reset / Power-Down)

The PN532 RSTPD_N pin controls reset and power-down modes. It must be driven
high (logic 1) for normal operation. Recommended connection:

- Pull up to +3.3V through a **10kΩ resistor** (same value as R1/R3/R4 already
  on the dabao_v3c board).
- Connect to a spare Baochip-1x GPIO (e.g. PB8) so firmware can reset the
  PN532 in software if needed — useful for error recovery without a full
  board power cycle.
- If software control is not needed, tie directly to +3.3V through the 10kΩ
  pull-up with no GPIO connection.

### H0 / H1 Interface Select Pins

The PN532 uses two pins (H0, H1) to select the host interface at power-up:

| H1 | H0 | Interface |
|---|---|---|
| 0 | 0 | I2C |
| 0 | 1 | SPI |
| 1 | 0 | HSU (UART) |

For SPI (recommended): tie **H1 to GND** and **H0 to +3.3V** through 10kΩ
pull-up resistors. These must be stable at power-up before RSTPD_N goes high.
