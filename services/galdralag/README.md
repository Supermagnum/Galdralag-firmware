# Galdralag Xous USB service (scaffold)

The **production** CCID / OpenPGP USB server for Baochip is **`usb-bao1x`** in the **xous-core** repository (feature **`ccid-openpgp`**), with **`crates/baochip-openpgp`** from this tree. See **`docs/RRAM_LAYOUT.md`** and the root **README** (**Known limitations / open work**).

This **`services/galdralag`** crate is not that server; it remains a placeholder if you want a separate entry point in this workspace.
